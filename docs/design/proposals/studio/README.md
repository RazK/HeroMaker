# Studio view: one carousel spine (proposal)

Drafted by Dana; reviewed and passed by Maya (2026-11-25). Not built yet. It waits for Raz.

- **One spine:** drawing → painting → 3D. One thin bar is both the cursor and
  the progress. The grape fill shows what is made; the knob shows where you
  are; the track shows what is not made yet. There are no dots and no ring.
- **The drawing** is a fixed polaroid at the top-left (-6°, 76 px at 390). It
  is never a slide and never covers the hero.
- **The peek:** 24 px of the next stage's plate, empty or locked. It never
  shows a second hero.
- **The pay state** is the built PaywallSheet (R4): a sheet on the phone and a
  centred 480 px dialog on desktop.
- **No filler text** (rule 53). The only text is the name card and the one
  action at the foot.
- **Real hero:** Violet Volt (26eef3df), with her real drawing, painting and
  3D render.

Frames: `making-*`, `pay-*`, `ready-*` (phone 390x844, desktop 1440x900, @2x).
