# Feature Launch Checklist

## Scope
- Problem / target user / expected KPI change:
- Feature owner:
- Non-goals:

## Build / quality
- [ ] Existing behavior understood and tested
- [ ] UX approved; loading/empty/error/success/rollback states handled
- [ ] Accessibility and mobile screen checks completed
- [ ] Privacy, security, permissions and data minimization reviewed
- [ ] Unit/integration/manual tests executed (record commands/results)
- [ ] Analytics definitions and event QA validated
- [ ] Localization, copy, support and help docs ready as needed
- [ ] Feature flag and rollback route available for risky changes

## Launch
- [ ] Human approval received for production/billing/comms
- [ ] Staged release or controlled test plan documented
- [ ] Monitoring and alerts assigned to owner
- [ ] Support escalation and incident plan known

## Post-launch
- [ ] Day-1 quality check
- [ ] Metric/guardrail checkpoint
- [ ] Decision: rollout / iterate / revert
- [ ] Learning and follow-up owner documented
