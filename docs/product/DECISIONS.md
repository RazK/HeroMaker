# Decisions

What Raz decided, from which evidence. Newest first. A decision is added when
he makes it, never before; it is not rewritten later: a reversal is a new
entry that names the one it replaces.

## Format

```markdown
## D-NNN: <the decision, one line>

- **Date:** YYYY-MM-DD
- **Decided by:** Raz
- **From:** E-NNN (result), H-NNN (now supported / rejected / inconclusive)
- **What changes:** the product, the price, the campaign, or nothing
- **Revisit when:** a date, or what would make us look again
- **Replaces:** D-NNN, if it does
```
